# TRYNKA-WEB v3
Демо-версія інтерфейсу: створення столів, параметри столу, три одразу роздані карти з повільним підгляданням, ДАВ/ВПАВ/ВСКРИВСЯ, чат, друзі, таблиця лідерів, профіль, XP та демо адмін-панелі для віртуальних фішок.

Поки це frontend demo: для справжньої синхронної гри між різними користувачами потрібен backend, база даних та авторизація.
