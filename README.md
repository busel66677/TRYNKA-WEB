# TRYNKA ONLINE v4
Це вже заготовка справжнього мультиплеєра через Supabase Realtime.

Є:
- реальні акаунти (анонімний вхід + нік);
- у лобі лише столи, де є люди;
- створення/вхід/вихід зі столу;
- друзі за ніком;
- запрошення друга за стіл;
- realtime список столів, гравців, чат і запрошення;
- 3 кнопки ДАВ / ВПАВ / ВСКРИВСЯ;
- повільне підглядання 3 вже розданих карт.

Потрібно один раз:
1. Створити Supabase project.
2. Увімкнути Anonymous Sign-ins в Authentication.
3. Виконати `supabase.sql` у SQL Editor.
4. Вставити Project URL та anon key у `config.js`.
5. Завантажити файли на GitHub Pages.

ВАЖЛИВО: карти та повна серверна логіка партії ще не захищені сервером. Наступний етап — серверна роздача, ходи, банк і правила.
